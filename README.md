# Cyberfyx Analysis

This repository contains a comprehensive analysis of the cyberfyx.net website to document its structure, service offerings, and underlying technology.

## Files and Directories

- **`cyberfyx_analysis_report.md`**: The primary analysis report containing the page-by-page breakdown, structural insights, and technical observations.
- **`raw_scraped_data/`**: A directory containing the raw text extraction of each page on the site. These files correspond directly to the findings in the analysis report and serve as an offline reference. You can see the direct mapping in the report's "Page-by-Page Analysis" section.
- **`scrape_to_txt.py`**: The Python script used to fetch the website's HTML and clean it into the raw text files for archiving.

## Highlights
During the analysis, we mapped out all core service pages (e.g., Cybersecurity, IT Security, Endpoint Management) and enumerated their content. We also discovered and documented several template leftover pages that reflect a previous or incomplete thematic setup (Logistics tools/FAQs). Detailed insights and security notes can be found in the analysis report.
